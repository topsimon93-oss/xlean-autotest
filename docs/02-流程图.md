## 图 2 · 一次完整测试运行流程(主流程)

```mermaid
flowchart LR
    S(["启动"]) --> ENV{环境检查<br/>Appium? 设备?"}
    ENV -- "未就绪" --> ERR["提示执行 setup_env / appium_install"] --> S
    ENV -- "就绪" --> RUN["pytest --platform &lt;平台&gt; --app &lt;App&gt;"]
    RUN --> CAP["组装 capabilities<br/>app 路径决策链"]
    CAP --> DRV["Appium 创建会话"]
    DRV --> INSTALL{"传了 --app?"}
    INSTALL -- "是" --> AP["安装 App → 启动"]
    INSTALL -- "否" --> LAUNCH["启动已安装的配置包"]
    AP & LAUNCH --> SMOKE["通用冒烟 5 步"]
    SMOKE --> P1["① 安装并启动"]
    SMOKE --> P2["② 首屏渲染"]
    SMOKE --> P3["③ 短时稳定性"]
    SMOKE --> P4["④ UI dump → xml"]
    SMOKE --> P5["⑤ 首屏截图"]
    P4 --> FEED["喂给 AI / 人工分析页面结构"]
    P1 & P2 & P3 & P5 --> ALLURE["Allure 结果 + 报告"]
    FEED --> POGEN["生成 PageObject & 业务用例"]
    POGEN --> REG["业务回归(全量用例)"]
    REG --> ALLURE
    ALLURE --> E(["交付: 报告/截图/xml 定位"])
```

## 图 3 · 新 App 接入 & 用例生产流程(「扔 App 给我」核心路径)

```mermaid
flowchart TB
    IN(["你: 扔一个 APK/IPA"]) --> APP[放入 apps/ 或指定路径]
    APP --> CFG{包名是否未知?}
    CFG -- 是 --> SMOKE0["跑通用冒烟(自动探测/启动)"]
    SMOKE0 --> DUMP0["得到: 启动是否成功 + 首屏 xml + 截图"]
    DUMP0 --> AI1["AI 从 xml 提取:<br/>包名/activity/关键元素 id/文本"]
    AI1 --> LOC["写入 config/local.yaml<br/>app_package / app_activity"]
    LOC --> WRITE["AI 生成 pages/* 页面对象<br/>+ testcases/* 业务用例"]
    WRITE --> RUN1["回归: pytest --platform android --app xxx"]
    RUN1 --> FIX{"通过?"}
    FIX -- 否 --> DEBUG["看 Allure 失败步骤/截图 → 修正定位"] --> RUN1
    FIX -- 是 --> DONE(["✅ 交付: 用例 + 报告 + 可复用资产"])
    CFG -- 已知(写过 local.yaml) --> WRITE
```

## 图 4 · Page Object 执行时序(运行时)

```mermaid
sequenceDiagram
    autonumber
    participant T as 测试用例
    participant P as PageObject(BasePage)
    participant D as Appium Driver
    participant AP as 被测 App

    T->>P: 业务动作 login('u','p')
    P->>P: _resolve(双端字典) 按平台取 (By,value)
    P->>D: WebDriverWait 等待元素可见
    D->>AP: 查询元素
    AP-->>D: 元素
    P->>D: click / send_keys(日志+中文描述)
    D->>AP: 执行交互
    P->>P: 失败? → 自动截图 + 抛清晰异常
    P-->>T: 返回业务结果
    T->>T: assert 断言
    Note over T,AP: Allure 自动记录步骤/日志/截图附件
```

## 图 5 · 平台隔离与用例筛选(运行期决策)

```mermaid
flowchart TD
    A(["pytest 启动"]) --> B["pytest_configure<br/>解析 --platform / --app / --with-demo"]
    B --> C["收集全部用例"]
    C --> D{"逐一判断 marker"}
    D -- "ios 标记 & 平台≠ios" --> SKIP["skip 标记(不报错)"]
    D -- "android 标记 & 平台≠android" --> SKIP
    D -- "demo 标记 & 未加 --with-demo" --> SKIP
    D -- "匹配当前平台" --> E["创建 session driver<br/>(整个 run 复用)"]
    E --> F["执行用例 → allure-results"]
    F --> G["teardown: 统一 quit 会话"]
    G --> H(["allure generate → 报告"])
```

## 图 6 · CI 流水线(建议落地形态)

```mermaid

    G(["Git Push / 定时"]) --> A["Job: Android(macOS/Windows runner)"]
```
