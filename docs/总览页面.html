📱 AppAutoTest

Android / iOS App 自动化测试框架 —— 扔一个 APK/IPA，就能测

Python + Appium 3.x + Pytest + Allure Page Object 双端定位 ✅ 框架就绪 ⚠️ 真机 e2e 待真实硬件验证

🚀 快速开始（Windows / Android）

STEP 0 · 一次性
环境准备
scripts\setup_env.bat
venv + 依赖 + Appium 驱动
STEP 1
起设备 + Appium
scripts\start_emulator.bat
scripts\start_appium.bat
STEP 2
扔 App 跑冒烟
APK 放入 apps\
run_tests.bat android apps\xxx.apk
STEP 3
看报告
scripts\allure_report.bat
自动打开 HTML 报告
最常用原始命令
cd AppAutoTest
.venv\Scripts\python -m pytest --platform android -q                          # Android 全量
.venv\Scripts\python -m pytest --platform android testcases/generic -q       # 只跑通用冒烟
.venv\Scripts\python -m pytest --platform ios -q                             # Windows 上 iOS 自动 skip
无设备快速验证: --platform android testcases/test_selfcheck_core.py

⚙️ 配置体系

三层叠加，优先级从低到高：config/global.yaml（默认） → config/local.yaml（个人，git 忽略） → CLI 参数（最高）。

默认被测包: com.android.settings权限弹窗: autoGrantPermissions 默认开平台隔离: pytest marker android/ios/generic

📐 双端定位符设计（核心）

# pages/xxx_page.py —— 同一元素给双端定位，字符串简写
class LoginPage(BasePage):
    username = {"android": "id=com.app:id/user", "ios": "aid=用户名输入框"}
    submit   = {"android": "xpath=//*[@text='登录']", "ios": "name=登录"}
    # 平台=android 取 android 定位符；平台=ios 取 ios 定位符
